GITHUB UPLOAD VERSION

This version keeps the website design but splits the large game HTML into 4 files so every file is below GitHub's 25 MiB browser-upload limit.

Upload these files to the ROOT of your GitHub repository:
- index.html
- credits.html
- game-part-1.txt
- game-part-2.txt
- game-part-3.txt
- game-part-4.txt

Do not upload the ZIP itself. Extract it first, then upload the files above.

For GitHub Pages:
Settings > Pages > Deploy from a branch > main > /(root) > Save

The Play buttons rebuild the original HTML in the browser. Load HTML / Copy HTML also rebuilds the same exact original game HTML.
